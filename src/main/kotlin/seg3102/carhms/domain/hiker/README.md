# Sous-domaine : Randonneurs (support)

Randonneur (identifié par son courriel) : noms, téléphone, adresse (objet-valeur), date de naissance,
personne-ressource en cas d'urgence (objet-valeur), niveau d'habileté, adhésion (ACTIVE, EXPIRÉE, SUSPENDUE),
acceptation de la décharge (et tuteur légal si mineur).

Organisateur : certification de chef de randonnée (numéro, délivrance, expiration) et niveau d'organisateur.

Code d'invitation : à usage unique, consommé à l'enregistrement.

Cas d'utilisation : Enregistrer un randonneur, Mettre à jour un randonneur.
