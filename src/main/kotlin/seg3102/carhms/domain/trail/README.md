# Sous-domaine : Sentiers (support)

Copie locale des sentiers publiés par la CCN : nom, type, surface, difficulté, saison d'ouverture,
secteur et zone, stationnement, tracé. Seuls les sentiers où la randonnée est permise sont retenus.

Le modèle de la CCN est traduit par une couche anticorruption ; le cache sert si la CCN est indisponible.
