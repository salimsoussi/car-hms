# Sous-domaine : Inscriptions (cœur)

Inscription : randonneur, randonnée, heure d'inscription, statut (CONFIRMÉE, EN_ATTENTE, ANNULÉE).

Règles : difficulté de la randonnée au plus un niveau au-dessus du niveau d'habileté ; adhésion active ;
liste d'attente dans l'ordre des inscriptions ; promotion automatique du premier en attente lors d'une annulation.

Cas d'utilisation : S'inscrire à une randonnée, Annuler une inscription, Parcourir les randonnées (vue par niveau).
